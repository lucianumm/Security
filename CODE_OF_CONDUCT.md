# Código de Conduta

O projeto Security recebe pessoas de diferentes experiências, origens e níveis de conhecimento.
Este código se aplica às issues, pull requests, revisões, discussões e demais espaços vinculados
ao projeto, inclusive quando alguém o representa publicamente.

## Compromisso da comunidade

- Trate as pessoas com respeito, independentemente de identidade, origem, idade, deficiência,
  religião, aparência, orientação sexual, formação ou experiência técnica.
- Discuta propostas e evidências com clareza. Critique a solução e explique o problema sem atacar
  a pessoa que contribuiu.
- Aceite correções, dê crédito ao trabalho de outras pessoas e ajude quem está começando.
- Respeite a privacidade e use exemplos sintéticos ao discutir falhas de segurança.
- Faça testes apenas em sistemas próprios ou com autorização e escopo definidos.

## Condutas incompatíveis

Não são aceitos assédio, discriminação, ameaças, insultos, exposição de dados pessoais, conteúdo
sexual direcionado a participantes, spam, intimidação ou perseguição. Também não são aceitos
publicação de credenciais, incentivo a ataques não autorizados, divulgação de dados de vítimas
ou uso de uma contribuição para executar ações ocultas no ambiente de outra pessoa.

Discordâncias técnicas e relatos de erros são bem-vindos quando apresentados de forma respeitosa.
O código não impede críticas fundamentadas ao projeto ou às decisões de manutenção.

## Como relatar um problema

Para uma denúncia reservada de conduta, entre em contato com o mantenedor pelo
[Instagram @lucianum](https://www.instagram.com/lucianum/), solicitando um canal privado adequado
antes de encaminhar detalhes sensíveis. Se houver abuso na plataforma, também é possível usar a
[denúncia de abuso do GitHub](https://support.github.com/contact/report-abuse).

Informe o contexto, os links relevantes e o comportamento observado. Compartilhe apenas os dados
necessários. Evite expor publicamente a pessoa afetada ou reproduzir conteúdo abusivo em uma issue.
Relatos de vulnerabilidades técnicas devem seguir a [Política de Segurança](SECURITY.md).

## Aplicação e responsabilidade

O mantenedor avalia cada situação, considera o contexto e pode solicitar esclarecimentos. As
medidas podem incluir orientação, advertência, edição ou remoção de conteúdo, encerramento de uma
interação ou restrição de participação, conforme a gravidade e a recorrência. A aplicação também
deve observar os termos e os recursos de moderação do GitHub.

As informações de uma denúncia serão tratadas com discrição e compartilhadas apenas quando
necessário para avaliar e resolver o caso. Não há promessa de prazo fixo para resposta.
