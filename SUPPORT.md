# Suporte e canais do projeto

Antes de abrir um pedido, consulte a [instalação e os exemplos no README](README.md#instalacao).
Informe o modo de uso, o ambiente, a versão ou commit da skill e o comportamento observado.

- **Dúvidas de uso:** use o [formulário de pergunta](https://github.com/lucianumm/Security/issues/new?template=question.yml).
- **Bugs reproduzíveis:** use o [formulário de bug](https://github.com/lucianumm/Security/issues/new?template=bug_report.yml), com dados sintéticos.
- **Sugestões:** use o [formulário de melhoria](https://github.com/lucianumm/Security/issues/new?template=feature_request.yml).
- **Catálogo e falsos positivos:** use o [formulário de revisão](https://github.com/lucianumm/Security/issues/new?template=catalog_review.yml).
- **Vulnerabilidade na própria skill:** siga [SECURITY.md](SECURITY.md) e o canal privado indicado.
- **Problemas de conduta:** siga [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Não publique tokens, chaves Pix de terceiros, documentos pessoais, dados de clientes, dumps,
configurações com segredos ou código privado. As evidências de uma aplicação auditada pertencem
ao responsável pela aplicação; este repositório não é o canal de divulgação de falhas de terceiros.

O suporte é comunitário, sem SLA ou compromisso de consultoria, auditoria profissional ou resposta
em prazo determinado. A manutenção pode solicitar uma reprodução mínima para investigar o caso.
